Comment ça marche

Quatre étapes. Aucun papier à remplir pour commencer.

1

Vous créez votre compte

Trois minutes. Vous cochez « Rejoindre le réseau » à l’inscription.

2

Vous recevez votre code

Un code à votre nom, du type PRÉNOM-XYZ, et un lien qui le transporte tout seul.

3

Vous en parlez autour de vous

Votre contact ouvre le lien, ou tape votre code au moment d’envoyer sa demande.

4

Vous êtes payé

Votre commission apparaît dès la commande confirmée, et vous est versée une fois que le client a réglé.

Les règles, sans petites lignes

Elles sont écrites une fois, elles valent pour tout le monde.

Première commande du client uniquement Un renouvellement chez un client déjà connu de Novogarden ne génère pas de nouvelle commission.
Trente jours d’attribution Votre code reste attaché à un client pendant trente jours après sa première saisie.
Versement après encaissement La commission se calcule dès que la commande est confirmée, et se verse quand le client a payé. Vous voyez les deux montants dans votre espace.
Vous ne voyez pas les coordonnées Dans votre espace, un client apporté apparaît en prénom, initiale et commune. Ni e-mail, ni téléphone : l’application ne vous les transmet pas.
Aucun objectif, aucun engagement Vous n’avez rien à vendre, rien à avancer, et rien à résilier. Si vous n’apportez personne, il ne se passe rien.

Ce qu’on attend de vous, comme testeur
